# 나만의 프롬프트 관리 프로그램

GenAI 미션을 수행하며 여기저기 흩어진 프롬프트를 **카테고리별로 분류하고, 키워드로 검색하고, 즐겨찾기로 관리**하는 Python 콘솔 프로그램입니다.
외부 라이브러리 없이 Python 기본 문법(변수, 조건문, 반복문, 리스트, 딕셔너리, 함수)만으로 만들었습니다.

## 실행 환경

- Python 3.10 이상 (`match-case` 문법 사용)
- 외부 라이브러리 설치 필요 없음

## 실행 방법

```bash
# 1. 저장소 내려받기
git clone https://github.com/<내-아이디>/prompt-manager.git
cd prompt-manager

# 2. Python 버전 확인 (3.10 이상)
python --version

# 3. 프로그램 실행
python prompt_manager.py
```

> Windows에서 기본 `python`이 3.10 미만이라면 `py -3.14 prompt_manager.py`처럼 버전을 지정해 실행하세요.

실행하면 메뉴가 나오고, 번호를 입력해 기능을 선택합니다. 각 기능이 끝나면 메뉴로 돌아오며, `0`을 입력하면 종료됩니다.

```
=== 나만의 프롬프트 관리 ===
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
8. 프롬프트 수정
9. 프롬프트 삭제
10. 인기 프롬프트 TOP 5
11. JSON 파일로 저장
12. JSON 파일에서 불러오기
13. 카테고리별 Markdown 내보내기
0. 종료
선택:
```

## 기능 목록

### 필수 기능

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 등록 (빈 값이면 다시 입력, 카테고리는 목록 선택 또는 직접 입력) |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호, 카테고리, 즐겨찾기(⭐)와 함께 출력 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 키워드가 제목 또는 내용에 포함된 프롬프트 검색 (대소문자 무시) |
| 5 | 프롬프트 상세 보기 | 번호를 입력하면 제목, 카테고리, 즐겨찾기 여부, 전체 내용 출력 |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아 보기 |
| 0 | 종료 | 프로그램 종료 |

- 목록, 검색, 카테고리 결과에 표시되는 번호는 모두 **전체 목록 기준 번호**라서, 그 번호를 그대로 상세 보기나 즐겨찾기 관리에 입력할 수 있습니다.
- 잘못된 번호를 입력하면 안내 메시지를 출력하고 메뉴로 돌아갑니다.
- 추가한 프롬프트와 즐겨찾기 상태는 **프로그램 실행 중에만 유지**되며, 종료하면 초기화됩니다.

### 보너스 기능

| 번호 | 기능 | 설명 |
|---|---|---|
| 8 | 프롬프트 수정 | 제목/내용/카테고리 수정 (Enter를 누르면 기존 값 유지) |
| 9 | 프롬프트 삭제 | 확인(y/N) 후 삭제 |
| 10 | 인기 프롬프트 TOP 5 | 상세 보기 횟수(조회수) 기준 상위 5개 출력 |
| 11 | JSON 저장 | 현재 프롬프트를 `prompts.json`으로 저장 |
| 12 | JSON 불러오기 | `prompts.json`에서 프롬프트를 불러와 현재 목록 교체 |
| 13 | Markdown 내보내기 | `export/` 폴더에 카테고리별 `.md` 파일로 내보내기 |

## 프롬프트 카테고리

| 카테고리 | 설명 |
|---|---|
| 텍스트 생성 | 설명, 글쓰기, 요약, 코드 리뷰 등 텍스트 답변을 받는 프롬프트 |
| 이미지 생성 | 이미지 생성 AI에 넣을 장면/스타일/비율 지시문 |
| 영상 생성 | 영상 스크립트, 장면 구성, 영상 생성 AI용 지시문 |
| 페르소나 | AI에게 특정 역할과 말투를 부여하는 설정 |
| 자동화 | 노코드 자동화 흐름에서 반복 실행하는 정형화된 프롬프트 |
| 기타 | 위 분류에 속하지 않는 프롬프트 |

### 기본 등록 프롬프트

이전 미션에서 작성한 학습용 프롬프트 4개가 기본으로 등록되어 있습니다. `[항목]: 값` 형식의 템플릿이라 괄호 부분만 바꿔서 바로 쓸 수 있습니다.

| 제목 | 카테고리 | 용도 |
|---|---|---|
| 개념 설명 요청 (재귀함수) ⭐ | 텍스트 생성 | 어려운 개념을 수준에 맞춰 실생활 예시로 설명받기 |
| 코드 오류 디버깅 요청 | 텍스트 생성 | 코드와 오류 메시지를 주고 원인 찾기 |
| 알고리즘 문제 풀이 도움 요청 | 텍스트 생성 | 막힌 지점을 알려주고 힌트 또는 전체 풀이 받기 |
| 코드 구조 복제 요청 (로그인 → 회원가입) | 텍스트 생성 | 기존 코드 구조를 그대로 두고 다른 기능으로 바꿔 받기 |

목록에 없는 카테고리는 프롬프트 추가 시 이름을 직접 입력해 만들 수 있고, 카테고리별 조회 목록에도 자동으로 나타납니다.

## 데이터 구조

프롬프트는 딕셔너리 하나로 표현하고, 전체는 리스트에 저장합니다.

```python
prompts = [
    {
        "title": "개념 설명 요청 (재귀함수)",
        "content": "[주제]: 재귀함수\n[수준]: 초보자\n[요청]: 개념을 실생활 예시로 설명해줘",
        "category": "텍스트 생성",
        "favorite": True,
        "views": 0,  # 보너스: 상세 보기 횟수
    },
]
```
